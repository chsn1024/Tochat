# 🤖 DeepSeek-ChatBot

A lightweight web chatbot powered by **Flask + DeepSeek API**, featuring **Markdown rendering**, **code highlighting**, and **dark/light theme toggle**.

---

## ✨ Features

- **Real-time conversation** with DeepSeek model  
- **Markdown rendering** & syntax highlighting (highlight.js)  
- **Dark / light theme switcher** with `localStorage` persistence  
- **Chat history** kept in memory (demo-level implementation)

---

## 🚀 Quick Start

### 1️⃣ Clone the repository

```bash
git clone https://github.com/chsn1024/Tochat.git
```
### 2️⃣ Create virtual environment & install dependencies
Create virtual environment:

```bash

python -m venv venv
Activate the virtual environment:

Windows: venv\Scripts\activate

macOS / Linux: source venv/bin/activate
```
